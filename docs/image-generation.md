# Image generation record

The retired photographic assets listed below were created with the built-in image generation tool. The supplied client screenshot was used only as a website mood, palette, lighting, and crop reference. These generated files were original placeholders; any people shown in them were fictional. They have since been removed from `public/images` and replaced by client-supplied photography documented in `docs/brand-assets.md`.

Shared prompt:

> Use case: photorealistic-natural. Asset type: Lina Studio Opava website photography. Create a new original premium editorial wellness photograph in a warm ivory boutique Pilates, barre, and reformer studio. Use cream, sand, pale oak, warm taupe, soft morning window light, realistic material and skin texture. No readable text, logo, watermark, or distorted anatomy/equipment.

Asset-specific requests:

- `hero-studio.jpg`: wide mirrored reformer studio with draped ceiling and negative space for hero copy.
- `studio-reformer.jpg`: close reformer, equipment shelving, exercise ball, and window light.
- `studio-private.jpg`: empty wide studio prepared for a private session.
- `class-barre.jpg`: fictional student from behind in a raised-arm barre position.
- `class-mat.jpg`: mats, low platform, small dumbbells, and resistance ball.
- `detail-barre.jpg`: shallow-focus pale oak ballet barre detail.
- `detail-balls.jpg`: three powder-blue Pilates balls in an ivory corner.
- `detail-matcha.jpg`: handmade ceramic cup of matcha in warm studio light.
- `detail-plaque.jpg`: completely blank limewash feature wall for the code-rendered SVG wordmark.
